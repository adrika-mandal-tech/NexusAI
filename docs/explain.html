NexusAI — How It Works

End-to-end RAG pipeline, workflows, and component interactions.

1. High-Level Pipeline

graph LR A[User uploads file] --> B[Parse text] B --> C[Chunk ~500 tokens / overlap 100] C --> D[BGE-M3 embeddings] D --> E[Qdrant vector store] D --> F[Neo4j graph entities] G[User asks question] --> H[Embed query with BGE-M3] H --> I[Retrieve top-k from Qdrant] I --> J[Fetch graph context from Neo4j] J --> K[Build grounded prompt] K --> L[LLM: Gemini / Groq] L --> M[Answer + citations]

2. Ingestion Workflow

sequenceDiagram actor User participant UI as Frontend participant API as FastAPI participant Pipe as Pipeline participant Emb as BGE-M3 participant Q as Qdrant participant N as Neo4j User->>UI: Upload file in Workspace UI->>API: POST /api/v1/knowledge/upload API->>Pipe: ingest_file() Pipe->>Pipe: extract text Pipe->>Pipe: chunk text Pipe->>Emb: embed_texts(chunks) Emb-->>Pipe: vectors Pipe->>Q: upsert vectors Pipe->>N: create nodes/edges Pipe-->>API: source_id, chunks API-->>UI: {source_id, status} UI-->>User: show ready + file size limits

3. Retrieval / Chat Workflow

sequenceDiagram actor User participant UI as Frontend participant API as FastAPI participant Emb as BGE-M3 participant Q as Qdrant participant N as Neo4j participant LLM as Gemini/Groq User->>UI: Send message UI->>API: POST /api/v1/knowledge/chat API->>Emb: embed_query(message) Emb-->>API: query vector API->>Q: query_points() Q-->>API: top-k chunks API->>N: get_graph() N-->>API: graph context API->>LLM: generate with context LLM-->>API: answer API-->>UI: {role, content, sources} UI-->>User: render answer + citations

4. Multi-Key & Model Routing

graph TD A[Incoming request] --> B{provider param?} B -->|gemini| C[Use Gemini] B -->|groq| D[Use Groq] B -->|auto| E{GROQ_API_KEYS set?} E -->|yes| D E -->|no| F{GOOGLE_API_KEYS set?} F -->|yes| C F -->|no| G[Return no-keys message] C --> H[Rotate Gemini keys] C --> I[Rotate Gemini models] D --> J[Rotate Groq keys] D --> K[Rotate Groq models] H --> L[Generate answer] I --> L J --> L K --> L
